| 项 | 内容 |
| :--- | :--- |
| 模块编号 | M01 |
| 优先级 | P0 |
| 对应总 PRD | §8.1 工作台、§9 RBAC |
| 主要读者 | 前端、后端 |
| 预估工作量 | 前端 5 人日 / 后端 3 人日 |

---

## 1. 模块目标

1. 用户能注册、登录、登出、保持登录态（access token 2h + refresh token 7d）。
2. 登录后落地页在 3 秒内回答三件事：**我今天要处理什么、我的图纸到哪一步了、AI 这周帮我拦了什么**。
3. 首页所有数字都能点进明细，不做"死指标"。
4. 菜单与按钮由后端返回的权限码驱动，前端不硬编码（RBAC 预留验收项之一）。

**不做**：第三方登录、短信验证码登录、找回密码邮件流（V1.0 由管理员重置密码）、深色模式、国际化。

## 3. 页面结构与路由

| 路由 | 页面 | 权限码 |
| :--- | :--- | :--- |
| `/login` | 登录页（独立布局，无侧边栏） | 匿名 |
| `/register` | 注册页 | 匿名 |
| `/` | 重定向至 `/dashboard` | 已登录 |
| `/dashboard` | 工作台首页 | `project:read` |
| `/projects/:id` | 项目详情（详见 prd-02） | `project:read` |

**全局框架（进入任何内页都渲染）**

```
┌──────────────────────────────────────────────────────────┐
│ [Logo] 项目管理  预审中心  批注    │ 搜索   🔔(3)  [头像▾] │  ← 顶栏 56px
├────────┬─────────────────────────────────────────────────┤
│ 侧边栏 │  主内容区（padding 24px，最大宽 1440px 居中）    │
│ 220px  │                                                 │
└────────┴─────────────────────────────────────────────────┘
```

- 顶栏铃铛：未读数 >0 时显示红底白字角标，>99 显示 `99+`。
- 头像下拉：个人信息、系统管理（仅 `system:user:manage` 可见）、登出。
- 侧边栏折叠态 64px 只显示图标，折叠状态存 `localStorage`。

## 4. 交互细节

### 4.1 登录页

**布局**：左侧品牌区（产品名 + 一句话价值 + 示意图），右侧表单卡（宽 400px）。窄屏（<1024px）隐藏品牌区。

**字段**

| 字段 | 类型 | 规则 | 错误提示 |
| :--- | :--- | :--- | :--- |
| 邮箱 | input[type=email] | 必填，RFC5322 简化校验 | "请输入有效的邮箱地址" |
| 密码 | password | 必填，长度 8~64 | "密码需 8~64 位" |
| 记住我 | checkbox | 默认勾选 | — |

**行为**

1. 提交按钮点击后进入 `loading`（禁用 + 转圈），禁止二次提交。
2. 成功后：写 token → 拉 `GET /auth/me` → 跳 `redirect` 查询参数指定的地址，无则 `/dashboard`。
3. 失败：**不在字段上分散报错**，表单顶部红色条显示后端 `message`；连续失败 5 次，后端返回 `429`，前端提示"尝试过于频繁，请 5 分钟后再试"。
4. `401 INVALID_CREDENTIALS` 统一提示"邮箱或密码错误"（不区分是哪个错，防枚举）。
5. 回车提交；Enter 在密码框即触发。

### 4.2 注册页

| 字段 | 规则 |
| :--- | :--- |
| 用户名 | 2~32 字符，中英文数字，唯一 |
| 邮箱 | 唯一，小写化后比对 |
| 密码 | 8~64，需含字母与数字（弱口令表拦截 top1000） |
| 确认密码 | 与密码一致，前端校验 |

注册成功 → 自动登录 → 落地 `/dashboard`，并弹出一次性引导（3 步：建项目 → 传图纸 → 看预审，可关闭，用 `localStorage` 记住已关闭）。

### 4.3 工作台首页

**区块顺序（自上而下）**

0. **（V1.0）流程暂停横幅**：`overview.pending_hitl > 0` 时在页面最顶部显示琥珀色横幅——"有 {n} 个预审正在等你确认，流程已暂停 · [立即处理]" 。点击进入最近一个待处理的预审页并自动弹窗。`pending_hitl = 0` 时**不渲染**（不占位）。
1. **欢迎条**：`早上好/下午好/晚上好，{用户名}` + 今日日期 + 右侧两个按钮：`新建项目`（主按钮）、`上传图纸`（次按钮）。上传图纸点击后先弹"选择项目"下拉（无项目则引导先建项目）。
2. **统计卡 ×3**（等宽三列，卡片高 120px）

| 卡片 | 主数字 | 副文案 | 环比口径 | 点击跳转 |
| :--- | :--- | :--- | :--- | :--- |
| 待审图纸 | 当前 `status ∈ {UPLOADED, PARSING, REVIEWING}` 的图纸数 | "其中 {n} 张预审中" | 无环比（存量） | `/projects?filter=pending-review` |
| 待处理批注 | 指派给我且 `status ∈ {PENDING_CONFIRM, ISSUED, MODIFIED}` 的批注数 | "其中 {n} 条待复核" | 无环比 | `/annotations?assignee=me&status=open` |
| 本周确认问题 | 我所在项目本周 `CLOSED` 且 `source=AI` 的批注数 | 环比上周 `+12%` / `-5%`，上升绿、下降灰 | 自然周（周一 00:00 起） | `/annotations?closed_this_week=1` |

> 环比计算：`(本周 - 上周) / max(上周, 1)`，上周为 0 时显示 "—" 不显示百分比（避免除零与误导）。

3. **待办中心**（占屏 60%）与 **最近项目**（右侧 340px 卡片列）左右两栏布局，响应式在 <1280px 时改为上下堆叠。

**待办中心表格**

| 列 | 宽 | 内容与规则 |
| :--- | :--- | :--- |
| 类型 | 88px | 标签：`批注`（蓝）/`预审`（紫）/`复核`（橙）/`项目`（灰） |
| 标题 | flex | 批注取 `annotation.title`；预审取 `drawing.name + " 预审"`；超长省略，hover 显示全文 tooltip |
| 所属项目 | 160px | `project.name`，可点击进项目 |
| 状态 | 96px | 见 §5 枚举映射 |
| 更新时间 | 120px | 相对时间（`3分钟前`/`昨天`/`03-12`），hover 显示绝对时间 |
| 操作 | 88px | `去处理` 文字按钮，点击按类型跳转 |

- 排序：`updated_at desc`；分页 10 条/页，卡片底部"查看全部"跳全量列表。
- 筛选：右上角 Tab 切换 `全部 / 批注 / 预审`，切换时保留滚动位置。
- 空态：插画 + "暂无待办，去上传一张图纸吧" + 上传按钮。
- 行 hover 背景 `#F5F7FA`，点击行进详情（不只是点按钮）。

**最近项目卡片**

- 每张卡片：项目名（粗体）、`图纸 12 · 未关闭批注 5`、最近更新时间、右上角"..."菜单（打开 / 重命名 / 归档）。
- 最多 6 张，超出显示"查看全部项目"。
- 空态："还没有项目" + 新建按钮。

### 4.4 全局登录态处理

| 场景 | 处理 |
| :--- | :--- |
| access token 过期 | 静默调 `POST /auth/refresh` 续期，成功后重放原请求（只重放一次，避免死循环） |
| refresh 也过期 | 清 token → 跳 `/login?redirect={当前路径}` |
| 接口返回 403 | 不跳登录，展示"无权限访问该资源"空状态页 |
| 多标签页登出 | 通过 `storage` 事件同步清态并跳登录页 |

## 6. 数据字段（工作台接口返回口径）

### 6.1 `GET /api/v1/dashboard/overview`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `pending_drawings` | int | 待审图纸数（UPLOADED/PARSING/REVIEWING） |
| `pending_drawings_in_review` | int | 其中预审中数量 |
| `pending_annotations` | int | 指派给我且未关闭的批注数 |
| `pending_annotations_to_review` | int | 其中 `MODIFIED` 数量 |
| `confirmed_issues_this_week` | int | 本周我所在项目 AI 采纳并关闭数 |
| `confirmed_issues_last_week` | int | 上周同口径 |
| `wow_change` | float\|null | 环比，null 表示上周为 0 |
| `ai_block_rate_this_week` | float | 本周 AI 拦截率 = 采纳数 / AI 输出总数，无数据返回 0 |
| `pending_hitl` | int | **V1.0**：等待我确认的风险/报告数（>0 时首页顶部显示琥珀横幅） |

### 6.2 `GET /api/v1/dashboard/todos?type=&page=&page_size=`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | uuid | 待办唯一 ID（由 biz_type+biz_id 组合生成） |
| `todo_type` | enum | 见 §5 |
| `title` | string | 展示标题 |
| `project_id` / `project_name` | uuid / string | 所属项目 |
| `status` | string | 原始状态枚举 |
| `status_text` | string | 后端下发中文，前端不再映射（保证一致性） |
| `biz_type` | enum | `ANNOTATION` / `REVIEW_TASK` / `DRAWING` |
| `biz_id` | uuid | 目标对象 ID |
| `deeplink` | string | 前端可直接 `router.push` 的路径，含定位参数 |
| `updated_at` | datetime | ISO8601 |

> `deeplink` 由后端拼装（如 `/projects/{pid}/drawings/{did}?annotation={aid}&focus=1`），前端禁止自行拼接，避免路径规则散落。

### 6.3 `GET /api/v1/auth/me`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` / `name` / `email` / `avatar_url` | — | 基本信息 |
| `roles` | string[] | 角色 code 列表，如 `["REVIEWER","ADMIN"]` |
| `permissions` | string[] | 权限码列表；`ADMIN` 返回 `["*"]`，前端按 `*` 视为全通 |
| `menus` | object[] | `{key, title, path, icon, children[]}`，已按权限过滤 |

## 7. 依赖接口

| 方法 | 路径 | 用途 |
| :--- | :--- | :--- |
| POST | `/api/v1/auth/register` | 注册 |
| POST | `/api/v1/auth/login` | 登录（返回 access + refresh） |
| POST | `/api/v1/auth/refresh` | 续期 |
| POST | `/api/v1/auth/logout` | 登出（refresh token 失效） |
| GET | `/api/v1/auth/me` | 当前用户 + 权限 + 菜单 |
| GET | `/api/v1/dashboard/overview` | 三张统计卡 |
| GET | `/api/v1/dashboard/todos` | 待办列表 |
| GET | `/api/v1/projects?sort=recent&page_size=6` | 最近项目 |

## 8. 异常与空态

| 场景 | 表现 |
| :--- | :--- |
| 首页接口任一失败 | 卡片显示 `—` + 重试按钮，不整页报错；失败卡片单独可重试 |
| 待办为空 | 插画 + "暂无待办，去上传一张图纸吧" + 上传按钮 |
| 最近项目为空 | "还没有项目" + 新建按钮 |
| 用户名过长（>12 字） | 欢迎条省略号截断，不换行 |
| 网络离线 | 顶部黄色条"网络已断开，数据可能不是最新" |
| 权限不足访问 `/dashboard` | 理论上不会发生（所有角色都有 `project:read`）；防御性展示 403 页 |

## 10. 验收标准

**功能**

- [ ] 注册 → 自动登录 → 落地首页，全程无刷新跳转错误
- [ ] 错误密码返回 401 且提示不区分邮箱/密码错误
- [ ] 连续 5 次失败触发 429，提示冷却时间
- [ ] 刷新页面后登录态保持；access 过期后静默续期，用户无感
- [ ] refresh 过期跳登录页并携带 `redirect`，登录后回到原页面
- [ ] 三张统计卡数字与数据库直查结果一致（构造 3 个项目、7 张图纸、5 条批注场景核对）
- [ ] 统计卡点击进入的列表页，条数与卡片数字一致（口径不漂移）
- [ ] 待办表格 5 列齐全，`去处理` 跳转后目标对象被高亮（依赖 prd-03 的 `focus` 参数）
- [ ] 待办为空展示空态插画与按钮，按钮可用
- [ ] 最近项目按 `updated_at` 倒序，最多 6 个

**权限**

- [ ] 移除当前用户 `project:read` 权限码后，`项目` 菜单消失，直接访问 `/dashboard` 返回 403 空状态页
- [ ] 管理员账号能看到"系统管理"菜单，非管理员看不到

**性能**

- [ ] 首页接口 P95 < 500ms（本地 10 万条批注数据量下）
- [ ] 首屏 TTI < 3s（4G 模拟、Chrome）

**兼容**

- [ ] 1366×768 下三卡不换行、待办表格无横向滚动
- [ ] 1920×1080 下内容区最大宽 1440px 居中，两侧留白
